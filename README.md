# Simple Apps

A collection of minimal, beautifully designed web tools — built with Next.js and deployed to GitHub Pages.

**[→ Live Demo](https://apps.pkdiv.com/)**

---

## Apps

### ⏱ Tap Counter

A sleek tally counter with a circular progress ring, customizable limits, and audio feedback.

- Tap right to increase, left to decrease — or use arrow keys / spacebar
- Set a custom limit and get an alarm when you hit it
- Ripple animations on every interaction
- Sound toggle, light/dark theme, state persisted in localStorage

### 🍅 Pomodoro Timer

A minimalist focus timer following the Pomodoro technique.

- **Focus → Short Break → Long Break** cycle with auto-progression
- Configurable durations for all three modes
- Circular progress ring with smooth countdown animation
- Session tracker (every 4th session triggers a long break)
- Audio notification on session completion
- Sound toggle, light/dark theme, state persisted in localStorage
